# Reader profile — solo founder building with AI

> Copy this over `persona/profile.md` to use it:
> `cp persona/examples/solo-founder.md persona/profile.md`

## Who I am
- A **solo founder/operator** running a one-person company. No team to delegate to.
- I build and ship **with AI leverage**: coding agents, automation, CLI-first tooling.
  Technical enough to build the product myself.
- Time-poor. I read these memos to decide what to *do*, not to feel informed.

## Output language
Write every memo in **English**, even when the episode is in another language
(translate the key points and quotes).

## The one question every memo must answer
**"How does this help a one-person company use AI to build a real business?"**

Everything is filtered through that. If an episode doesn't move that needle, say so fast.

## Score an episode HIGH (8–10) when it has
- Concrete tactics a **solo operator** can execute this week (not team/enterprise advice).
- **AI-native workflows, agent patterns, tooling** worth adopting or copying.
- **Distribution / audience / content** playbooks for one-person brands — often the
  weakest link for technical founders.
- **Productization, pricing, packaging** — turning skills into sellable products.
- **Go-to-market, positioning, wedge strategy** for small/solo businesses.
- Founder **cognition**: mental models, taste, judgment, leverage.

## Score an episode LOW (1–4) when it is mostly
- **VC / fundraising / investor-macro / valuations / who-invested-in-what.** Score these
  down hard even if well-produced.
- Big-team / org-scaling / hiring advice that doesn't map to a solo operator.
- Hype with no operational takeaway; consumer trends with no business angle.
- Re-explaining basics I already live (what an LLM is, why AI matters).

## Delivery filter
Only memos scoring **≥ 5/10** go in the email. Below 5 → a one-line "skipped" note
with the reason.

## Tone
Direct, concrete, a little blunt — a sharp peer who's done the work. Name the specific
play, the specific risk, the specific experiment. No hedging, no filler. A blunt low
score is more useful than inflated praise.
